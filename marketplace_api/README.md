# Ventul — Marketplace API

Ventul is the community commerce module of the Tulancingo Connect Platform. It provides a secure RESTful API for listing, discovering, and transacting with local products and services, connecting buyers and sellers across Tulancingo's neighborhoods.

## Key Features

- **Product listings**: Create, update, and manage local product and service offerings.
- **Search & discovery**: Filter by category, location, price, and seller rating.
- **Secure transactions**: Integrated payment gateway support with local payment options.
- **Seller profiles**: Verified merchant pages that build community trust.
- **Integration**: Works hand-in-hand with the Cargo-GO logistics engine for order fulfillment.

## Social Impact in Tulancingo

Ventul democratizes commerce for Tulancingo's informal and formal economies alike. By providing a digital storefront to artisans, street vendors, and SMEs, it helps them reach a broader local audience without the high fees of national e-commerce platforms, thereby keeping economic value circulating within the community.

## Getting Started

```bash
# Install dependencies (Python)
pip install -r requirements.txt

# Run the development server
python main.py
```
