# Cargo-GO — Logistics Engine

Cargo-GO is the professional logistics module of the Tulancingo Connect Platform. It powers hyper-local delivery coordination, route optimization, and real-time shipment tracking for businesses and individuals within the Tulancingo metropolitan area.

## Key Features

- **Last-mile delivery**: Efficient routing for local couriers and small carriers.
- **Real-time tracking**: Live status updates for senders and recipients.
- **Fleet management**: Tools for managing delivery vehicles and schedules.
- **API integration**: RESTful endpoints that connect seamlessly with the Ventul marketplace and Denarytor civic modules.

## Social Impact in Tulancingo

Cargo-GO reduces logistics costs for micro and small enterprises (MiPyMEs) that have historically relied on expensive third-party couriers. By enabling affordable, community-first delivery infrastructure, it strengthens the local supply chain and creates employment opportunities for local couriers.

## Getting Started

```bash
# Install dependencies (Python)
pip install -r requirements.txt

# Run the development server
python main.py
```
