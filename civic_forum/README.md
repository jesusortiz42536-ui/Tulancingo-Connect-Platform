# Denarytor — Civic Forum

Denarytor is the civic engagement module of the Tulancingo Connect Platform. It provides a structured digital space for residents, local organizations, and government bodies to discuss community issues, propose initiatives, and vote on local decisions that shape Tulancingo's future.

## Key Features

- **Threaded discussions**: Organized forums for neighborhoods, topics, and civic projects.
- **Proposal system**: Citizens can submit, endorse, and comment on civic proposals.
- **Community voting**: Transparent polling on local issues and initiatives.
- **Moderation tools**: Ensures respectful and constructive dialogue.
- **Event board**: Announcements for local events, town halls, and public consultations.

## Social Impact in Tulancingo

Denarytor strengthens participatory democracy at the hyper-local level. By giving every Tulancingo resident a digital voice — from colonias rurales to urban neighborhoods — it bridges the gap between citizens and local authorities, reduces civic apathy, and fosters a culture of collective responsibility and transparent governance.

## Getting Started

```bash
# Install dependencies (Python)
pip install -r requirements.txt

# Run the development server
python main.py
```
